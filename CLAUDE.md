# modelizmclub

## Анимации появления и серверная разметка

**Не задавайте `initial` компонентам первого экрана.**

framer-motion записывает проп `initial` инлайн-стилем прямо в серверный HTML.
Содержимое приезжает с сервера готовым — и невидимым до конца гидрации.
Пользователь смотрит на пустое место, браузер не считает элемент отрисованным,
LCP уезжает на время загрузки и разбора бандла.

Замерено на проде 05.09 при 1,6 Мбит/с и 4× CPU:

| Страница | Узел | В DOM | Видно | Разрыв |
| --- | --- | --- | --- | --- |
| `/feed` | карточка поста | 2,5 с | 6,2 с | **3,7 с** |
| `/profile` | содержимое вкладки | 1,7 с | 4,6 с | **2,9 с** |
| `/feed` | баннер (до починки) | 3,1 с | 6,8 с | **3,7 с** |

Во всех трёх случаях данные пришли вовремя. Ждали не их.

### Как надо

Для появления при монтировании — `<Appear>` из `@/components/ui/Appear`.
Он не задаёт начальное состояние на первом рендере (ни на сервере, ни при
гидрации) и анимирует только то, что смонтировано позже: переключение вкладки,
догрузку страницы ленты, ответ на действие.

```tsx
// было: прячет карточку до гидрации
<motion.div initial={{ opacity: 0, y: 8 }} animate={{ opacity: 1, y: 0 }}>

// стало
<Appear>
```

Для смены содержимого по ключу — `<ReducedMotionSwitch>`; он по умолчанию не
анимирует первый отрисованный кадр. Ставьте `animateOnMount` только если
уверены, что блока в серверной разметке нет.

### Когда `initial` уместен

- **Блоки ниже сгиба с `whileInView`.** Они прячут то, чего пользователь ещё
  не видит. Вреда нет, проверять не нужно.
- **Диалоги, меню, тосты, шторки.** Их вообще нет в первом рендере — они
  появляются по действию.

### Как проверить

```bash
curl -s https://modelizmclub.ru/feed | grep -c 'opacity:0'
```

Ноль на первом экране. Если больше — найдите узел и посмотрите, виден ли он
без JS. Разрыв между «пришло в DOM» и «стало видно» измеряется наблюдателем
`largest-contentful-paint` и опросом `getComputedStyle(el).opacity`.

## Прочее

- Не создавайте второго, если есть первое: `PostCard`, `lib/gate`,
  `ui/avatar`, `formatDate`, токены из `docs/design-system.md`.
- Слои — только из шкалы в `styles.css` (`--z-sticky` … `--z-call`),
  числовых `z-index` у плавающих элементов быть не должно.
- Перед коммитом: `deploy/scripts/check-workspace.sh` — посторонние файлы под
  `frontend/src` компилируются tsc и сбивают порог перед мержем.
