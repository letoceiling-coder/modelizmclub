## `40-api-contract.md` — договор API

**Расходится сильно, и это опаснее прочего.** Контракт описывает форму
ответов, по которой пишут клиенты. За три недели изменились, как
минимум:

- `offers_cdek` у объявления — теперь означает «предлагает СДЭК», а не

- ответ списка категорий несёт `posts_count`, `listings_count`,
  `has_admin` (C2);
- карта доступа `GET /admin/access` несёт `granted` — права,
  выданные поверх роли (C3);
- список акций несёт `state`, `seats_left`, `days_left`,
  `days_until_start` (C4);
- объявление несёт автора с рейтингом (использовалось и раньше,
  но в контракте не описано);
- отказ при отправке SMS несёт `code` и `retry_after`, в том числе при
  429 (D3 и починка 26.09).

Живой источник — `php artisan scramble:export` и `docs/API.md`.

## Предложение 26.09 уже выполнено наполовину

Тогда я предлагал пометить пакет снимком, дописав дату и живой источник
в шапку каждого файла. **Это сделано:** все девять файлов несут строку
«Снимок <дата> (<коммит>)» третьей строкой, а `21-routes-api.md` — ещё и
имя скрипта, которым пересобирается.

Чего не было: **живой источник назван не у всех**. У маршрутов API он
стоял, у модели данных, договора API и платежей — нет. Дописано 30.09,
тем же коммитом: теперь каждый файл пакета говорит, куда идти за
сегодняшним состоянием.

Смысл именно в этом: устаревшая запись хуже отсутствующей ровно тем, что
не заставляет пойти и проверить. Ссылка на живой источник заставляет.

## Что я предлагаю

Переписывать пакет целиком сейчас не стоит: он потеряет ценность
снимка и не станет надёжнее живых источников. Каждый его раздел уже
имеет живую замену:

| Раздел снимка | Чем заменяется |
| --- | --- |
| Маршруты API | `php artisan route:list` |
| Модель данных | `backend/database/schema/objects.txt` |
| Договор API | `docs/API.md`, Scramble |
| Замеры | ворота CI и замеры в ветках |
| Платежи | `deploy/docs/vtb-go-live.md` |

Предлагаю пометить пакет снимком — дописать дату и строку «состояние на
03.09, живой источник такой-то» в шапку каждого файла — и оставить.
Это дешевле переписывания и честнее: устаревшая запись хуже
отсутствующей ровно тем, что не заставляет пойти и проверить, а ссылка
на живой источник заставляет.

Решение за вами. Если нужно переписать — это отдельная задача, и по
объёму она сравнима с самим пакетом.
