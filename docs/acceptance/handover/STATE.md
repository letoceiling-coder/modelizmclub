### Ловушка замера, в которую я попал и из которой вышел

Первая проверка вебсокета дала **500** и выглядела как поломка. Причина — в
измерителе: `curl` договорился с сервером по HTTP/2, а рукопожатие вебсокета
по HTTP/2 так не делается, и nginx честно ответил 500. С `--http1.1` — 101,
как и напрямую в reverb на `127.0.0.1:8080`. Браузер ходит по HTTP/1.1, то
есть дефекта нет. Записано по правилу `CLAUDE.md` «прежде чем записывать
отсутствие — напечатайте, что именно нашёл замер».

## Что мешало работать

`deploy/scripts/check-ci-status.sh` на этой машине **не может спросить CI**:
он ходит в GitHub по `GH_TOKEN`, а токен лежит в связке ключей `gh`, не в
окружении. Ответ — «спросить не удалось — Not Found», и по правилу проекта
это «не зелёный». CI я смотрел через `gh api` напрямую. В `MORNING.md`.

`deploy/scripts/smoke-check.sh`, запущенный на вашем компьютере, половину
проверок делает по путям `/var/www/modelizmclub/...`, которых локально нет, и
печатает «выяснить не удалось» плюс ложное `FAIL schema drift` по пустой
локальной базе. Правильный ответ даёт только запуск на сервере. Тоже в
`MORNING.md`.
