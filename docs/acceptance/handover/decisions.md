## Что эти решения перекрывают

**З2 перекрывает решение 27.08** (часть 2.5 Библии) в части требования
подтверждённого телефона: раньше телефон требовался для «действий с людьми»
широким списком, теперь — только публикация объявления и вывод средств.

**З3 перекрывает поведение окна верификации**, описанное в разборе 07.09
(`CLAUDE.md`, «Проверять до выкатки»): окно больше не открывается по коду
`phone_not_verified` из любого фонового запроса.

**З5 меняет часть 4.1 Библии**: автопубликация записей ленты включается.
Объявления — как было, с проверкой до публикации.

**З7 и З8 вместе** означают: первая волна открывается без приёма денег, и
проверочный платёж делается только после того, как штатная проверка
(`deploy/scripts/check-live-money.sh --require-live`) скажет «боевой».
