## Чем поднимается стенд

```bash
service postgresql start && service redis-server start
cd backend && PHP_CLI_SERVER_WORKERS=10 php artisan serve --host=127.0.0.1 --port=8000 &
cd frontend && VITE_API_URL=http://127.0.0.1:8000 bun run build
PORT=3000 VITE_API_URL=http://127.0.0.1:8000 TZ=UTC node .output/server/index.mjs &
```

`PHP_CLI_SERVER_WORKERS=10` обязателен: однопоточный `artisan serve`
отдаёт 503 на параллельных запросах, и замер превращается в выдумку.
