# Что сделать до запуска

По порядку. Каждый пункт: что сделать, кто делает, что получить и куда
передать, как убедимся, сколько ждать внешнюю сторону, блокирует ли запуск.

«Блокирует» означает два разных запуска:
**БП** — без платежей (сайт работает, оплаты выключены, объявления
бесплатны, безопасной сделки нет).
**СП** — с платежами (подписка, платное размещение, безопасная сделка).

Названия настроек даны без значений. Все серверные — в `backend/.env`,
если не сказано иное; после правки `.env` нужен
`php artisan config:cache && chmod 640 backend/bootstrap/cache/config.php`.

## 4. Банк ВТБ и безопасная сделка

**Что уже написано.** Приём денег — `VtbAcquiringGateway`, выплаты —
контур `VTB_PAYOUT_*`, залог безопасной сделки идёт через тот же
эквайринг. Пока контур выключен, приём уходит на заглушку `/pay/stub`
с выбором исхода. Есть разбор зависших платежей
(`payments:reconcile-pending`), автоматическое снятие залога
(`safe-deals:auto-release`), опрос банка по расписанию.

**Важно.** Умолчания на испытательный узел **убраны**: без явного адреса
контур считается ненастроенным и деньги не принимаются. Проверка
`check-no-sandbox-defaults.sh` в воротах CI не даёт вернуть песочницу.
