## 4. Ключи облачного хранилища: что сейчас и как перевыпустить

### Что настроено сейчас

Значения ключей не печатаю. Вот всё остальное:

| Параметр | Значение |
| :-- | :-- |
| Провайдер | **Selectel**, объектное хранилище S3 |
| Точка входа | `https://s3.ru-3.storage.selcloud.ru` |
| Регион | `ru-3` |
| Контейнер (bucket) | `knowledge-raw` |
| Диск приложения | `s3` |
| Ключ доступа | задан, 32 символа |
| Секретный ключ | задан, 32 символа |

Переменные в `backend/.env`: `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`,
`AWS_ENDPOINT`, `AWS_DEFAULT_REGION`, `AWS_BUCKET`,
`AWS_USE_PATH_STYLE_ENDPOINT`.

Имена с `AWS_` — это не Amazon: так называется стандартный набор настроек
S3 в Laravel, Selectel работает по тому же протоколу.

### Порядок перевыпуска

Ключи вводите вы. Я проверяю результат. Порядок важен: **сначала создать
новый, потом переключить, и только потом удалить старый** — иначе сайт
останется без картинок на время между шагами.

**Шаг 1. Создать новый ключ (делаете вы).**

1. Войдите в панель Selectel: `my.selectel.ru`.
2. Слева выберите **«Объектное хранилище»**.
3. Откройте раздел **«Пользователи»** (в некоторых версиях панели —
   «Сервисные пользователи» или «Ключи доступа S3»).
4. Найдите пользователя, от имени которого работает контейнер
   `knowledge-raw`.
5. Нажмите **«Создать ключ S3»** (или «Добавить ключ доступа»).
6. Панель покажет **Access Key** и **Secret Key**. Секретный ключ
   показывается **один раз** — скопируйте оба сразу.

Старый ключ на этом шаге **не трогайте**: пока он жив, сайт работает.

**Шаг 2. Вписать новый ключ (делаете вы, я подсказываю куда).**

Файл: `/var/www/modelizmclub/backend/.env` на боевом сервере.
Две строки:

```
AWS_ACCESS_KEY_ID=<новый Access Key>
AWS_SECRET_ACCESS_KEY=<новый Secret Key>
```

Остальные четыре строки не меняются.

После правки нужно, чтобы приложение перечитало настройки. Скажите мне —
я выполню по вашей команде:

```
php artisan config:cache && chmod 640 bootstrap/cache/config.php
systemctl reload php8.3-fpm
```

`chmod` здесь обязателен: `config:cache` создаёт файл с правами 644, а
внутри него пароль базы открытым текстом.

**Шаг 3. Я проверяю, что новый ключ работает.**

Без вашего участия, только чтение и одна тестовая загрузка во временный
файл:

- чтение существующего файла из контейнера — отдаётся;
- загрузка пробного файла — проходит;
- удаление пробного файла — проходит;
- страница с картинками на сайте открывается, картинки грузятся.

**Шаг 4. Удалить старый ключ (делаете вы).**

В той же панели Selectel удалите **старый** ключ — тот, что был до
04.10.

**Шаг 5. Я проверяю, что старый ключ больше не действует.**

Попробую обратиться к хранилищу старым ключом и покажу вам отказ. Если
старый ключ всё ещё работает — значит удалён не тот, и я скажу об этом.
