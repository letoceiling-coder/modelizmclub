# Фактическая матрица доступа на 04.10.2026

Снята в рантайме из `App\Support\FeedGuestAccessRegistry::actions()` —
того самого реестра, по которому сервер решает, пускать или нет. Это
умолчания из кода; админка хранит поверх них свою карту, и расхождение
между кодом и сохранённой картой ловит `access-map-drift.sh --strict`
в воротах CI.

Всего действий в карте — **60**. Уровни: `гость` → `вошёл` → `подписка`.

| Подмена роли, статуса, баланса, владельца в теле правки | три проверки того же файла | PASS |

Доказательство откатом — в докблоке теста. Коротко: снятие
`RejectBlockedAccounts` с группы `api` краснит три проверки; чтение роли
из тела в `AuthService::register` краснит проверку регистрации. Отдельно
записано, чего откат **не** ломает: замена `validated()` на `all()` в
`UpdateProfileController` все проверки оставляет зелёными, потому что
правка профиля пишет в `UserProfile`, у которого нужных колонок нет вовсе.

## Чего этой ночью не проверялось

| Что | Почему |
| :-- | :-- |
| Возобновление действия после входа (нажал лайк гостем, вошёл в окне, лайк поставился) | нужен живой вход в браузере; на проде вход под учётками запрещён, локальный стенд не поднимался |
| Десять гостевых сценариев на экране, 360 px и 1280 px | то же; серверная часть покрыта, экранная — нет |
| Текст окна «Добавьте пользователя в друзья» | серверное правило проверено, формулировка на экране — нет |

Матрица доступа **уже проверялась экраном** 27.09: 22 действия × 5
состояний, 110 запросов, все четыре инварианта держались
(`docs/acceptance-verdict.md`). Этой ночью перепроверялась серверная
часть и закрывались места без тестов.

## Два пункта меню строже страницы за ними

Разбор по сохранённой карте прода (ветка `fix/nav-not-stricter-than-page`,
не влита) называет ровно две пары из двенадцати:

| Пункт меню | Уровень пункта | Страница | Уровень страницы |
| :-- | :-- | :-- | :-- |
| `layout.nav.communities` | `подписка` | `route.communities` | `гость` |
| `layout.nav.channels` | `подписка` | `route.channels` | `гость` |

Гость видит пункт, нажимает и получает окно подписки вместо открытой ему
страницы. В умолчаниях кода (матрица ниже) оба пункта стоят `гость` — то
есть расхождение живёт в карте, сохранённой в админке на проде, а не в
коде. Поведение этой ночью не менялось: это договорённость 05.09, и
правка требует решения владельца (см. `REQUIREMENTS.md`, REQ-181).
