### Отдельно: локальный прогон через `artisan test` не проходит

```
DB_DATABASE=… php artisan test              → Allowed memory size of 134217728 bytes exhausted (api.php line 23)
DB_DATABASE=… php -d memory_limit=1G artisan test → то же самое
DB_DATABASE=… php -d memory_limit=2G vendor/bin/phpunit → OK
```

Причина: `memory_limit` в `php.ini` машины — 128 МБ, а набору нужно 177,5 МБ.
`php -d memory_limit=…` при этом **не помогает**, потому что `artisan test`
запускает phpunit отдельным процессом и флаг командной строки туда не
доезжает. В CI этого не видно: `shivammathur/setup-php` ставит
`memory_limit=-1`.

То есть «локальные ворота» на свежей машине падают не на коде, а на
настройке, и падают сообщением про `api.php`, по которому причину не
угадать. Запись для `MORNING.md` и `known-issues`.

`GET api/v1/admin/diagnostics`, закрытого `auth:sanctum` + админским
middleware.

соблюдён, а буква («404») — нет. Поведение этой ночью **не меняется**,

есть сервер различать умеет и 200 у `/diag` — следствие существования
маршрута, а не отсутствия обработки 404.
