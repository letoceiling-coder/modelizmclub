**Где.** Главная живого сайта, `https://modelizmclub.ru/`.
**Роль.** гость. **Ширина.** любая (находка в разметке).

**Шаги.** Запросить главную без скриптов и посчитать теги `h1`.

**Ожидание.** Один заголовок первого уровня — так работает `master`
после `64f93388`.

сайте присутствуют, то есть сайт стоит ровно на один коммит позади.

**Причина.** Коммит `64f93388` слит в `master` 08.10 в 17:00 и не выкачен.

**Правка.** Не нужна: код готов. Закрывается выкаткой в промпте 07.
Это же закрывает вторую половину A-01 из аудита.

**Чем доказано.** `curl` главной прода и стенда, подсчёт вхождений
`grep -ao '<h1' | wc -l` (вхождениями, не строками — по правилу
`CLAUDE.md`).
