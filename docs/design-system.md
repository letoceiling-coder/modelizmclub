# Дизайн-система: токены, шкала, кнопки

Одна страница-справочник. Живой showcase — `/admin/design-system` (под админом,
работает и в prod). Источник токенов — `frontend/src/styles.css`, кнопки —
`frontend/src/components/ui/button.tsx`.

## Шкала отступов

Используется **дефолтная шкала Tailwind v4**: `--spacing = 0.25rem = 4px`.
Собственных `--spacing-*` в `@theme` нет — дефолт покрывает все значения,
встречающиеся в проекте. Точные px в классах отступов запрещены для нового
кода (eslint `no-restricted-syntax`, уровень `warn`); существующие ~2200
вхождений мигрируют волнами (W4-09).

### Таблица замены px → токен

| px | шаг | классы |
|---:|----:|--------|
| 2 | 0.5 | `p-0.5` `gap-0.5` `m-0.5` |
| 4 | 1 | `p-1` `gap-1` `m-1` |
| 6 | 1.5 | `p-1.5` `gap-1.5` |
| 8 | 2 | `p-2` `gap-2` `m-2` |
| 10 | 2.5 | `p-2.5` `gap-2.5` |
| 12 | 3 | `p-3` `gap-3` `m-3` |
| 14 | 3.5 | `p-3.5` |
| 16 | 4 | `p-4` `gap-4` `m-4` |
| 20 | 5 | `p-5` `gap-5` |
| 24 | 6 | `p-6` `gap-6` `m-6` |
| 32 | 8 | `p-8` `gap-8` |
| 40 | 10 | `p-10` |
| 48 | 12 | `p-12` |

Правило: `p-[12px]` → `p-3`, `gap-[6px]` → `gap-1.5`, `-mt-[8px]` → `-mt-2`.
Значение, которого нет в таблице (например 18px или 22px) — почти всегда
ошибка макета; округляйте к ближайшему шагу. Если оно действительно нужно
(выравнивание по чужой иконке), оставьте px и добавьте комментарий — линт
это только предупреждение.

Что правило **не** трогает: `w-[…px]`, `h-[…px]`, `top/left-[…px]`,
`rounded-[…]`, `text-[…px]` — это размеры и позиции, а не шкала отступов.
Для них есть свои токены: радиусы `--r-*`, шрифты `--fs-*`, высоты шапок
`--mobile-header-h` / `--desktop-topbar-h`.

## Типографика

Заголовки страниц — `--fs-h1…h4` (Space Grotesk). Для контента карточек и
списков четыре утилиты из `styles.css` (`@utility`):

| класс | размер / интерлиньяж / вес | где |
|-------|---------------------------|-----|
| `text-card-title` | 20px / 1.3 / 600 | заголовок карточки, поста, объявления |
| `text-body` | 16px / 1.5 | основной текст |
| `text-meta` | 14px / 1.4 | город, цена, автор, статус |
| `text-caption` | 12px / 1.3 | дата, счётчики, подписи |

Одна и та же сущность (пост, объявление, комментарий) на всех страницах
рисуется одними и теми же классами — это и есть «один вид».

## Брейкпоинты и ширины контента

Mobile-first: базовые классы — для 375, модификаторы добавляют, а не
переопределяют.

| точка | Tailwind | раскладка | ширина контента |
|------:|----------|-----------|-----------------|
| 375 | (base) | одна колонка, нижняя навигация, шапка `--mobile-header-h` 52 | 100% − 2×16px |
| 768 | `md:` | колонка шире, сетки по 2, боковые панели скрыты | 100% − 2×24px |
| 1280 | `xl:` | sidebar `--sidebar-w` 240 + центр + правая панель `--rightrail-w` 320 (где она есть) | до `--container-max` 1560, поля `--container-pad` |

`lg:` (1024) используется точечно — момент появления сайдбара. Не вводите
новых промежуточных точек без причины.

### Правая панель: есть или нет

Решает маршрут, а не страница: `lib/layout/rails.ts`, оболочка —
`AppLayout` (проп `rail` только для исключений).

| | колонки | центр |
|---|---|---|
| с панелью — лента, сообщества, каналы, друзья | 240 · центр · 320 | содержимое до 680, по центру дорожки |
| без панели — мессенджер, обзоры, каталог, мои объявления, избранное, настройки, баланс | 240 · центр | всё место до правого края, без ограничения |

На страницах без панели своих `max-w-… mx-auto` у корня страницы не
ставить — это снова пустота справа. Левая колонка и левый край центра у
обеих раскладок одинаковы, поэтому переход между ними не сдвигает разметку.

### Левое меню: свёрнутое

Каталог и объявление — `<AppLayout navCollapsed>` во всех состояниях
страницы (загрузка, ошибка, заглушка): меню — значки 64 на всех ширинах,
дорожка `4rem`, как у Авито. Остальные страницы — 240 от 1280, значки ниже.

- Наведение разворачивает полное меню поверх содержимого (`--z-dropdown`),
  раскладка не двигается.
- Кнопка внизу колонки закрепляет развёрнутым, та же — сворачивает. Только
  от 1280: ниже полной колонки нет нигде.
- Выбор — `lib/store` (`navExpanded`, ключ `modelizm:leftnav:expanded`),
  читается после гидрации: сервер всегда рисует свёрнутым.
- Активный раздел в значках — фон `accent-soft`, цвет `accent`.

### Сетка каталога

`components/ads/catalogGrid.ts` — одна строка на каталог и его заглушку:
`repeat(auto-fill, minmax(min(220px, 120px + 13%), 1fr))`, по ширине
самой сетки, не по брейкпоинту. Карточек в ряду: 2 на 375, 3 на 768,
3 на 1024, 4 на 1440. Карточка — картинка 4:3, цена `text-body`
полужирным, название `text-meta` в две строки, город `text-caption`;
высота не больше 320.

### Страница объявления

Две полосы и лента, как у Авито (`routes/ads.$id.tsx`):

| полоса | слева `minmax(0,1fr)` | справа `360` |
|---|---|---|
| верх | галерея | цена и действия (липнут в пределах полосы) |
| низ | описание и характеристики | доставка, продавец, «Спросите у продавца» |
| лента | похожие во всю ширину, каруселью | — |

Правая колонка нижней полосы — только если в ней есть что показать; иначе
описание во всю ширину. Зазоры между блоками 16 / 24 от 1024.

- Галерея: кадр не выше 400 с 768 и 480 с 1024, фото целиком (`contain`).
- Клик по фото и по любой миниатюре — полноэкранный просмотр
  `components/post/Lightbox`, тот же, что в ленте. Второй не заводить.
  В нём: фото целиком, стрелки и ←/→, счётчик, Esc, крестик, клик по
  затемнению (от 1024; ниже окно во весь экран), свайп, зум кликом ×2 и
  колесом до ×4, фокус возвращается туда, откуда открыли.
- Описание — `CollapsibleText`, 6 строк на телефоне и 16 от 1024
  (`maxLinesLg`), дальше «Показать полностью».

### Мессенджер

Правой панели нет — две колонки (`routes/messenger.tsx`): список диалогов
`360` от 1280 и `320` на 768–1279, переписка — всё остальное. Ниже 768
список и переписка — отдельные экраны с переходом.

- Пузырь: радиус 16, у последнего в серии угол 4 со стороны отправителя;
  не шире 70 % колонки; свои — справа на `accent`, чужие — слева на
  `background-surface`. Время — `text-caption` обычным шрифтом, приглушённое,
  в правом нижнем углу, галочки рядом. Серия — подряд от одного автора:
  аватар и (в групповых чатах) имя только у первого. Разделитель «Новые
  сообщения» рвёт серию.
- Появление пузыря — `Appear`: анимируется только то, что пришло после
  открытия чата, первый экран виден сразу.
- Строка списка — `DialogRow` (memo): новое сообщение поднимает диалог
  наверх, остальные строки не перерисовываются. Непрочитанное — жирные имя
  и превью, счётчик акцентным кружком; прочитанное — обычным весом. Своё
  последнее — «Вы: ». Имя и аватар — `dialogIdentity` для любого типа.
- Эмодзи — один `components/messenger/EmojiPicker` на всё приложение:
  мессенджер, комментарии, чат направления, композер записи, репост, правка
  записи, запись канала. Полный набор `emojibase-data` (ru) отдельным чанком
  при первом открытии, категории, поиск, недавние. В модальном окне панель
  рисуется внутри окна — иначе клик по смайлу закрывал бы окно.

## Кнопки

`components/ui/button.tsx`, cva. Тап-таргет на мобильном — **44px** минимум
для основных действий.

### Приоритет (variant)

| variant | когда | вид |
|---------|-------|-----|
| `primary` | одно главное действие на экране («Написать», «Подать объявление») | заливка `--accent` |
| `secondary` | второе по важности («Позвонить», «Сохранить черновик») | тёмная заливка `--neutral-900` |
| `tertiary` | третье и далее («Пожаловаться», «Ещё») | текст `--foreground-70`, без рамки, нейтральный hover |
| `detached` | кнопка вне группы, на любой подложке («Подписаться» в шапке сущности) | рамка + приподнятый фон + лёгкая тень |
| `icon` | только иконка | квадрат, ghost-hover; всегда с `aria-label` и `size="icon"` |

Legacy-имена, которые остаются для существующего кода и **не** используются
в новом: `default` (= `primary`), `outline`, `ghost`, `commercial`,
`destructive`, `success`, `link`. Из них `commercial` и `destructive` —
осмысленные и живут дальше; `outline` → `detached`, `ghost` → `tertiary`
при миграции.

### Размер (size)

| size | высота | использовать |
|------|-------:|--------------|
| `sm` | 36 | плотные списки, вторичные действия в строке таблицы |
| `md` | 44 | всё остальное — основной размер |
| `icon` | 44×44 | только с `variant="icon"` |
| `default` | 40 | legacy, не для нового кода |
| `lg` | 44 | legacy (= `md` с большим паддингом) |

### Анатомия

- Высота фиксирована размером; ширина — по контенту, в мобильных
  CTA-панелях `w-full` или `flex-1`, чтобы кнопки одного ряда были равной
  ширины.
- В одном ряду — не больше одной `primary`. Две кнопки одного веса рядом —
  `primary` + `secondary`, не две `primary`.
- Иконка внутри текстовой кнопки — 16px (`[&_svg]:size-4` из базы), в
  `icon`-кнопке — 20px (`size-5`).
- `loading` — единый спиннер, кнопка блокируется; `disabled` — серые
  `--neutral-200/400`, без тени.
