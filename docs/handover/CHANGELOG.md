## 09.10, вечер — срочная починка подтверждения телефона

Выкатка `be4e85d5`. Четыре жалобы живого пользователя.

### Код из SMS

- Код уходил в сообщение **числом**, и ведущие нули терялись: `001234`
  печаталось как «1234». Каждый десятый код начинается с нуля — то есть
  один человек из десяти получал код короче, чем требует форма.
- Поле ввода кода **исчезало при возврате на страницу**: человек уходил
  читать SMS, возвращался — вписывать было некуда, оставалось запросить
  новый код и отменить полученный. Теперь поле стоит всегда.
- Длина кода собрана в **одно место**. Было шесть независимых записей
  шестёрки в коде сервера и три в интерфейсе; настройка для неё
  существовала и не использовалась ни разу.
- Поле кода стало одним общим: цифровая клавиатура, подсказка кода из SMS
  над клавиатурой, вставка целиком, отправка на последней цифре, подпись
  «Код из N цифр».

### Где требуется телефон

- Подтверждённый телефон требовался на **134 адресах сервера** — включая
  чат сообщества и чтение закладок. Осталось **четыре**: создать
  объявление, опубликовать объявление, вывести деньги, сменить реквизиты
  выплаты.
- Посредник, требовавший сразу почту и телефон, разделён на два: снять
  телефон, не сняв заодно почту, иначе было нельзя.
- Мессенджер и сообщества открываются без подтверждённого телефона.
- Флаги «можно / нельзя» в ответах сервера приведены к новому правилу: без
  этого человек без телефона не видел бы кнопок, которые ему разрешены.

### Всплывающее окно

- Окно «Подтвердите номер» открывал **любой** неудачный фоновый запрос.
  Человек ничего не нажимал, окно появлялось само; закрывал — следующий
  запрос открывал снова. Теперь окно открывает **нажатие**, а не ответ.
- Закрытое окно помнится до конца захода.
- Телефон убран из лестницы доступа: учётка без номера открывала платный
  раздел и получала «Подтвердите номер» вместо окна подписки — хотя
  подтверждение номера доступа туда не давало.
- Плашка про телефон снята с ленты и подписки и говорит настоящую причину.
