## A-08 · P2 · Блок «три шага» на главной не виден без скриптов

**Где.** Главная, блок с тремя шагами.
**Что происходит.** Пять узлов приходят с сервера с `opacity:0` и
становятся видны только после выполнения скриптов.

```bash
curl -s https://modelizmclub.ru/ | grep -ao 'opacity:0' | wc -l
# 5
```

**Чем мешает.** Без скриптов и при печати блока не видно. Скорости не
вредит: узлы ниже первого экрана.
**Оговорка.** В аудите числится исправленным — на проде воспроизводится.

## Дерево направлений рассогласовано — 20 узлов · P2

**Что происходит.** У двадцати направлений в полях `depth` и `path`
записано, что у них есть родитель, а в `parent_id` родителя нет.

**Чем НЕ мешает.** Дерево, которое видят люди, строится по `parent_id` —
проверено запросом к боевой выдаче. Полки каталога сошлись 72 из 72, сирот
нет, страницы открываются.

**Чем мешает.** Проверка целостности красная при каждой выкатке, и красная
проверка прячет следующее настоящее расхождение.

**Починка готова, штатная, идемпотентная:**

```bash
ssh -p 2222 root@31.207.75.124 \
  "cd /var/www/modelizmclub/backend && php artisan categories:normalize --dry-run"
# убедиться, что итог сходится, затем без --dry-run
```

Холостой прогон проверен: итог — ноль расхождений в обоих деревьях. Я её не
применил: запись на прод заблокировала защита от изменения общих данных.

## Окно доступа не закрывается при переходе внутри сайта · P3

**Что происходит.** Человек открыл `/reviews` — там нужна подписка, окно
появилось правильно. Перешёл на `/deals`, где подписка не нужна, — окно
уехало с ним и говорит, что нужна.

**Как поймать.** С полной перезагрузки `/deals` чист; воспроизводится только
переходом внутри сайта.

**Чем мешает.** Человек думает, что раздел платный, хотя он открыт.

## Запись «код использован» и «код отменён» — одна колонка · P3

**Что происходит.** `phone_verification_codes.used_at` ставится в двух
случаях: код приняли и код отменил новый. По базе их не отличить.

**Чем мешает.** Разбор жалоб на SMS. Ночью 10.10 по этой колонке сначала
показалось, что код приняли, — на деле его отменил следующий запрос. Правду
сказали только `attempts = 0` и пустой `phone_verified_at`.

**Починка.** Отдельная колонка `cancelled_at`. Это миграция и пересборка
эталона схемы — десять минут отдельной веткой.

## Два пункта меню строже страницы за ними · P3

`layout.nav.communities` и `layout.nav.channels` стоят в сохранённой карте
доступа на уровне «подписка», а сами страницы открыты гостю. Гость видит
пункт, нажимает и получает окно подписки вместо открытой ему страницы.

В умолчаниях кода оба пункта стоят «гость» — расхождение живёт в карте,
сохранённой в админке. Правится галочкой в разделе «Доступ».
