# Сценарий приёмки

**30–40 минут, с телефона.** Адрес: https://modelizmclub.ru

Проходите по порядку. В последнем столбце ставьте отметку: ✅ принято,
❌ не принято. Где не приняли — напишите пару слов, что увидели.

Понадобится: телефон с интернетом, ваша почта, ваш номер телефона.
Второй человек не нужен — там, где нужна вторая сторона, сказано отдельно.

## Часть 1. Гостем, без входа (5 минут)

Откройте сайт в **режиме инкогнито** — так браузер не подставит ваш прежний
вход.

| 1.2 | Нажать «Принять» на баннере cookie | Баннер исчезает и больше не возвращается | ☐ |
| 1.3 | Прокрутить главную до конца | Текст читается, картинки видны, вбок страница **не ездит** | ☐ |
| 1.4 | Меню → «Лента» | Лента открывается, записи видны | ☐ |
| 1.5 | Нажать на любую запись | Запись открывается целиком | ☐ |
| 1.6 | Меню → «Объявления» | Каталог открывается, карточки с ценами видны | ☐ |
| 1.7 | Нажать на объявление | Карточка открывается, видно продавца и цену | ☐ |

## Часть 3. Подтверждение телефона (5 минут)

| № | Что нажать | Что должно получиться | Принято |
| :-- | :-- | :-- | :-- |
| 3.1 | Настройки → «Профиль и аккаунт» → блок «Телефон» | Видно поле номера, кнопку «Отправить SMS» и **поле для кода** — оно есть сразу | ☐ |
| 3.2 | Ввести свой номер, нажать «Отправить SMS» | «Код отправлен по SMS» | ☐ |
| 3.3 | Дождаться SMS | Код пришёл. **Цифр в нём ровно шесть** | ☐ |
| 3.4 | **Выйти со страницы и вернуться** (или перезагрузить) | Поле для кода **на месте**, вводить есть куда | ☐ |
| 3.5 | Ввести код | Подтверждается само, без нажатия кнопки: «Номер телефона подтверждён» | ☐ |
| 3.6 | Вернуться в блок «Телефон» | Написано «Подтверждён по SMS» | ☐ |

**Пункты 3.3 и 3.4 — вторая главная жалоба.** Раньше код приходил короче,
чем требовала форма, а поле исчезало при возврате на страницу.
