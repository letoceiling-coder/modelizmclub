## 6. Восстановить подписку 1273

**Проверено, как она устроена.** Подписка `id=60`, план 38,
`granted_by_admin_id=1207` — то есть выдана администратором, и держалась
именно этим признаком. Сейчас:

```
статус: cancelled   starts_at: 2026-09-20 14:26:58   ends_at: 2026-09-23 20:12:28
```

Приложение считает подписку действующей, если есть строка со `status =
active`, непросроченным `ends_at` **и** одним из признаков: оплата,
выдача админом или промо первой сотни. У 1273 нет ни оплаты, ни
`is_first_hundred` — держал только `granted_by_admin_id`. Он на месте,
поэтому достаточно вернуть статус и срок:

```bash
ssh -p 2222 root@31.207.75.124 'cd /var/www/modelizmclub/backend && php artisan tinker --execute='"'"'
$u = \App\Models\User::find(1273);
$s = \App\Models\UserSubscription::find(60);
echo "ДО: ", $s->status, " до ", $s->ends_at, " действует=", ($u->hasActiveSubscription() ? "да" : "нет"), PHP_EOL;
$s->update(["status" => "active", "ends_at" => "2027-09-20 14:26:58", "cancelled_at" => null]);
$u->refresh();
echo "ПОСЛЕ: ", $s->fresh()->status, " до ", $s->fresh()->ends_at, " действует=", ($u->hasActiveSubscription() ? "да" : "нет"), PHP_EOL;
'"'"''
```

Проверка — `действует=да` в строке ПОСЛЕ. Без неё восстановление будет
только на вид: строка в базе изменится, а доступа человек не получит.

Время в `ends_at` — московское стенное, как и всё в этих колонках. Час
`14:26:58` взят от исходной выдачи, чтобы год считался ровно.
