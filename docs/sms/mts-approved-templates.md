# Согласованные SMS-шаблоны МТС (MODELIZM)

Имя отправителя: **MODELIZM**  
Юрлицо: ООО «МОДЕЛИЗМ», ИНН 2312341754

Реализация: `App\Services\Sms\SmsTemplate` + `SmsMessenger`.

| Ключ | Назначение | Тип |
|------|------------|-----|
| `verification` | Регистрация / верификация | Сервисный |
| `login` | Вход по SMS-коду | Сервисный |
| `password_reset` | Восстановление пароля | Сервисный |
| `phone_change` | Смена телефона | Сервисный |
| `ad_publish_verify` | Верификация перед публикацией объявления | Сервисный |
| `ad_published` | Объявление опубликовано | Транзакционный |
| `ad_rejected` | Объявление не прошло модерацию | Транзакционный |
| `ad_payment_received` | Оплата размещения | Транзакционный |
| `ad_expiring` | Истекает размещение | Транзакционный |
| `chat_message` | Новое сообщение в чате | Транзакционный |
| `community_approved` | Заявка в сообщество одобрена | Транзакционный |
| `subscription_*` | Подписки | Транзакционный |
| `deal_*`, `order_*`, `seller_payout` | Безопасная сделка | Транзакционный |
| `new_review` | Новый отзыв | Транзакционный |
| `referral_reward` | Реферальная программа | Транзакционный |
| `welcome`, `draft_reminder`, `new_device_login` | Онбординг / безопасность | Сервисный |
| `promo_*` | Рекламные | Рекламный |

Тексты шаблонов — в enum `SmsTemplate::render()`.
