## Стенд: как поднять заново

Контейнер временный. Всё, кроме репозитория, после сессии исчезает.

```bash
pg_ctlcluster 16 main start
redis-server --daemonize yes --save '' --appendonly no
cd backend && php artisan serve --host=127.0.0.1 --port=8000 &
cd frontend && npx vite dev --host 127.0.0.1 --port 3000 &
```

| Служба | Адрес |
| :-- | :-- |
| База стенда | `modelizmclub_dev`, роль `modelizmclub`, пароль `secret` |
| База тестов | `modelizmclub_test` (как в CI) |
| API | `http://127.0.0.1:8000` |
| Фронтенд | `http://127.0.0.1:3000` |

Признак «Сообщества» на стенде включён и должен оставаться включённым.
Очередь и вебсокет не поднимались.

Грабли окружения, на которых терялось время (подробно в `baseline.md`):

1. `bun install --frozen-lockfile` **возвращает 0**, не скачав восемь
   пакетов из закрытого реестра. Ставить их из публичного `registry.npmjs.org`.
2. Тесты бэкенда гонять **как CI**: `php artisan test --env=testing`.
3. `composer install` **переписывает `origin`** рабочего дерева. После него
   всегда `git remote -v`.
4. Прокси отвергает прод; ноль в ответе `curl -s` означает «запрос не ушёл».
