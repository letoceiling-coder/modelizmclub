## Что нужно знать, чтобы стенд заработал

Подробно — в `baseline.md`. Три вещи, на которых сессия 1 потеряла время:

1. `bun install --frozen-lockfile` **возвращает 0**, не скачав восемь
   пакетов: лок-файл адресует их в закрытый реестр Lovable, доступа нет.
   Без них нет `vite.config.ts` → нет сборки → нет `src/routeTree.gen.ts` →
   `tsc` сыпет `TS2345` на каждом `createFileRoute`. Лечится установкой этих
   восьми из публичного `registry.npmjs.org`, где они есть.
2. Тесты бэкенда гонять **как CI**: `php artisan test --env=testing` с
   `.env.testing.example` и базой `modelizmclub_test`. С `.env` стенда
   падают два теста ВТБ, и это не дефект.
3. `composer install` **переписал `origin` рабочего дерева** на
   `https://github.com/symfony/polyfill-php80.git` — часть пакетов ставится
   клонированием, и git-окружение утекло. Пуш после этого отвергается
   прокси. Проверять `git remote -v` после `composer install`; вернуть:
   `git remote set-url origin https://github.com/Neeklo1606/modelizmclub.git`.
