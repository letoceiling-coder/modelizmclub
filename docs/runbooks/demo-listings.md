# Подкатегории направлений и тестовые объявления

Согласовано с заказчиком 12.09. Две команды, обе с `--dry-run` и с проверкой
результата отдельными запросами по факту в таблицах.

## Подкатегории — `categories:add-subcategories`

Список узлов — в самой команде (`AddDirectionSubcategoriesCommand::PLAN`):
38 новых узлов, из них 6 третьего уровня. Узел заводится тем же путём, что в
админке: строка в `post_categories`, затем зеркало в каталог объявлений и в
категории сообществ через `CategoryTaxonomyService::syncFromPostCategory`.

```bash
php artisan categories:add-subcategories --dry-run   # план и все записи в зеркала
php artisan categories:add-subcategories             # запись и проверка
```

- Направление, у которого нет ни одного зеркала, синхронизируется целиком,
  вместе с уже заведёнными подкатегориями. У отражённого (Авиация,
  Бронетехника, Рыбалка) — только новые узлы: полная синхронизация
  перевесила бы существующие зеркала («ил 6» в каталоге висит под Авиацией,
  а в дереве направлений — под Планерами).
- Запись в зеркало, которая заняла бы чужую строку с тем же slug, —
  конфликт: команда останавливается до записи.
- Без подкатегорий остаются Kotello, АкваРобот и Каналы.
- Цены размещения у новых категорий каталога не заданы — действует цена
  родителя или общая.

## Тестовые объявления — `listings:demo`

```bash
php artisan listings:demo --dry-run                  # план по узлам
php artisan listings:demo                            # создать и проверить
php artisan listings:demo --only=armor-spg,armor-rc  # только эти узлы
php artisan listings:demo --purge --dry-run          # что будет удалено
php artisan listings:demo --purge                    # удалить всё
```

**Пометка.** Продавцы — `seller1…seller4@demo.modelizmclub.ru`; по домену
объявления находятся и удаляются. Первая строка каждого описания —
«Тестовое объявление — не продаётся.»: лоты публичные, и покупатель должен
видеть, что покупать нечего.

**Что создаётся.** 2–3 лота на узел (`App\Support\DemoListingCatalog`), две
картинки-заглушки на лот (`DemoImageFactory`: цветной фон и подпись), город
из первых 25, доставка «Почта России» и «Самовывоз». Объявление создаётся
`ListingService::create` с `taxonomy_id` узла — черновиком, без оплаты
размещения, — и публикуется `markPublished`, как при одобрении модерацией.
Платежей не появляется.

**Где объявлений нет.** Выставки и события, Обзоры наборов, Техники и
мастер-классы, Каналы, Kotello, АкваРобот, Рыбалка → Трофеи и Водоёмы —
продавать там нечего. «ил 6» — объявление перевесило бы его зеркало в
каталоге, а узел оставлен как есть.

**Удаление.** `--purge` удаляет продавцов `UserFullDeletionService` (тем
же, что `user:purge`); объявления, привязки фото и избранное уходят
каскадом. Если по демо-объявлению есть безопасная сделка, команда
отказывается: каскад удалил бы и сделку покупателя. Файлы картинок в
хранилище остаются — как при любом полном удалении пользователя.
